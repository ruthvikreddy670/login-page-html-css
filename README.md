# Driver Login – Login Page using HTML & CSS

An animated, responsive login page with a **night drive** theme, built using only **HTML5** and **CSS3** (no JavaScript).

![Driver Login preview](assets/preview.png)

## Live Demo

https://ruthvikreddy670.github.io/login-page-html-css/

## Features

- **Username / Email** and **Password** fields
- **Login** button ("Start Engine")
- **Remember Me** checkbox
- **Forgot Password?** link
- **Sign Up** link for new users
- Fully **responsive** for mobile, tablet and desktop
- Smooth **hover animation** on the login button (engine shake, red glow and pulse ring)

## Animations

- Highway in 3D perspective with lane markings rushing towards you
- Red, white and amber light trails from passing cars
- City skyline with lit windows on the horizon
- Carbon fibre login card that drifts in from the side
- Rev counter whose needle revs up to the red line and settles at idle
- Respects the user's "reduce motion" setting

## Technologies Used

- HTML5
- CSS3 (Flexbox, gradients, keyframe animations, 3D transforms, media queries)
- Google Fonts: Teko and Rajdhani
